# 사용자 중심 화면 개선 — 2026-10-01

## 사용 순서

1. 출발지·도착지·이사일·이사 종류와 참고사항을 입력한다.
2. **내 상황 정리하기**를 누른다. Supervisor가 초기 계획을 1회 호출로 만들고 물품 표를 채운다. 아직 Worker는 실행하지 않는다.
3. **물건을 이렇게 정리하면 될까요?**에서 틀린 처리 방식·규격·전문 작업 여부만 수정한다.
4. **확인했어요 · 체크리스트 만들기**를 누른다. 임시 초기 계획을 재사용하고 Worker 네 명과 최종 검토를 실행한다. 정상 전체 흐름은 1+5=6회다. 캐시 장애·만료 시 계획을 다시 호출할 수 있다.
5. 결과 상단의 **먼저 준비할 일** 최대 5개를 확인한다. 미완료 이사 전 작업 중 선행조건이 충족된 작업을 먼저, 그 안에서는 권장 준비 시점 순으로 보여준다. 실제 마감일이나 새로 생성한 별도 작업이 아니다.
6. 각 작업을 **준비 전 / 진행 중 / 완료**로 관리한다. 상단과 전체 목록은 같은 작업 상태를 공유한다.
7. 엘리베이터·주차, 인터넷, 가스, 폐기 접수, 자녀·돌봄 작업 카드에 확인 내용을 입력하고 해당 조건으로 목록을 갱신한다.

## 학습 기능 유지

모델 배정·병렬 실행 설정, 모델 계약 점검, 실행 기록·State·출력 계약은 각각 **자세히 보기 · 학습용 …**에 유지했다. Trace 내부는 일반 컨테이너로 표시하여 expander를 중첩하지 않는다. 전체 확인 사항 입력과 상황 요약도 접어서 볼 수 있다.

## 현재 한계

진행 중 상태는 브라우저 세션 및 다운로드에 반영한다. 서버의 기존 완료 표시 임시 저장 API는 완료 항목만 저장하므로 불러올 때 완료 이외 항목은 준비 전으로 복원된다. 입력 조건 변경 시 다른 목록으로 취급하여 진행 상태는 다시 확인해야 한다. 원문을 변경하면 내 상황 정리부터 다시 진행한다. 삭제한 추출 물품을 원문에서도 제외하려면 참고사항을 수정해야 한다.

## 검증

화면 테스트에서 결과 표시 예외가 없고 우선 목록과 전체 목록의 진행 중 상태 동기화를 확인했다. 자동 테스트에는 초기 계획 확인 단계에서 Worker가 실행되지 않고 확인 후 5회로 이어지는 경로를 추가했다. 실제 모델을 사용한 새 2단계 흐름의 재실행은 이번 검증에서 수행하지 않았다.
